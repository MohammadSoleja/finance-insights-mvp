## 📝 Documentation Guidelines

### For Contributors

When adding new documentation:

1. **Place files in appropriate directories:**
   - Feature docs → `features/`
   - Bug fixes → `fixes/`
   - UI changes → `ui-improvements/`
   - Implementation guides → `implementations/`
   - Playbook-related → `playbook/`
   - AI-related → `ai-integration/`
   - Troubleshooting → `troubleshooting/`
   - Security → `security/`

2. **Use descriptive filenames:**
   - FEATURE_NAME_DESCRIPTION.md
   - BUG_FIX_DESCRIPTION.md
   - IMPLEMENTATION_FEATURE_NAME.md

3. **Include these sections:**
   - Summary
   - What changed
   - Why it changed
   - How to use/test
   - Related files
   - Status/completion

4. **Update this README.md** when adding new documentation
